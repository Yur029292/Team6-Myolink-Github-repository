# M03

I doubt part of our session design. In sessions 2, 3 and 5 we changed only one electrode, so the placement was almost the same as the session before. The model may learn that placement and look better than it really is. I support that the test session changed both active electrodes, which makes the final score fairer. Next time, I would replace all three electrodes in every session.

Source: Hargrove, L., Englehart, K., & Hudgins, B. (2006). The effect of electrode displacements on pattern recognition based myoelectric control. Conference Proceedings : ...
